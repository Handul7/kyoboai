# 교보 뉴스브리핑

보험업 주요 이슈를 읽고 근거 기사를 확인하는 공개 보고서 도우미입니다. 브리핑에는 원문을 대조해 작성한 이슈 보고서와 PDF가 있습니다. 발행 회차나 월을 골라 열람할 수 있습니다.

## 기간 수집과 부서 역할

1. **뉴스 링크 확인**에서 언론사 기사 주소를 입력하면 원문 제목·발행일을 확인하고 관련 보도 후보를 최대 7건 찾습니다.
2. **주차별 확인**에서는 월과 주차를 고르면 그 주 월요일부터 일요일까지(이번 주는 한국 시간 오늘까지) 참고 매체 10곳에서 검색되는 기사를 모읍니다.
3. 최종 수정일 옆 **API 키 입력**을 누르면 GPT와 Jev 개인 키를 각각 연결하거나 해제할 수 있습니다. 기사 링크와 주차별 확인에서 Jev는 기사 중요도와 관련 부서를 판단합니다. 결과의 **GPT 요약 생성**을 누르면 기사 제목을 바탕으로 출처가 달린 요약을 만듭니다. 연결은 같은 탭에서 새로고침해도 이어지며 새 탭에서는 다시 연결합니다.
4. **부서 역할**에서 2026년 10월 23일 경영조직도에 따른 검토 부서를 분야나 키워드로 찾습니다. 부서를 펼치면 검토 업무, 먼저 확인할 일, 키워드, 대응하는 직무기술서 목록 또는 참고 자료를 확인할 수 있습니다. 업무 분야와 기준은 뉴스 분류용으로 작성했으며, 방문자가 기준을 편집하면 그 브라우저의 다음 판단부터 적용됩니다.

월요일은 목~일, 목요일은 월~수 기사를 오전 7시 기준으로 묶습니다. 수동 실행은 정기 발행 설정을 변경하지 않습니다. 공개 검색에서는 제목·매체·발행일·링크를 사용합니다. 공개 모드의 Jev는 기사 제목·메타데이터와 선택한 부서 기준을 사용합니다. 기간 검색은 새 LLM 보고서를 자동 발행하지 않습니다.

## 실행

Node.js 22.13 이상으로 `npm test`, `npm run build`, `npm run dev` 순서로 실행합니다. 로컬 주소는 `http://127.0.0.1:4173/#collect`입니다. 로컬 DB는 `.local-data/`에 저장합니다. 정적 화면은 `npm run build:static`으로 빌드할 수 있습니다. 기간 수집과 Jev는 Worker와 D1을 사용합니다.

## 배포

서비스는 [kyoboai.handul.dev](https://kyoboai.handul.dev/) 한 곳에서 운영하며, Sites의 Cloudflare Worker·D1에서 실행합니다. Cloudflare DNS의 `kyoboai` CNAME은 `custom-domains.chatgpt.site`를 가리킵니다. [Handul7/kyoboai](https://github.com/Handul7/kyoboai)의 `main`이 원본이며, 이전 GitHub Pages 배포는 종료했습니다.

현재 버전은 `release.json`과 모든 화면 상단에서 확인합니다. 이전 변경은 Git 이력에서 확인할 수 있습니다.

GitHub `main`을 원본으로 관리합니다. GitHub 푸시만으로 Worker가 자동 배포되는 워크플로는 아직 없습니다. 릴리스 순서는 (1) 같은 소스의 검사·빌드, (2) GitHub 저장, (3) 기존 Sites 프로젝트에 동일 파일로 버전 저장·배포, (4) 대표 주소의 `release.json`과 GitHub 파일 대조입니다. 저장소별 커밋 SHA는 달라도 되며 배포 파일 내용이 같아야 합니다. 환경 변수와 로컬 DB는 복사하지 않습니다. 다음 업데이트에서는 DNS를 바꾸지 않습니다.

## 담당 산하별 읽기와 검토

- 브리핑은 발행된 주요 회차를 함께 보여주며 회차·담당 산하로 좁힐 수 있습니다. 부서 기준은 직속 상위 조직 16개 아래의 23개 부서로 탐색합니다. 업무 분야는 보조 필터입니다.
- 상세 보고서는 핵심 수치와 기준, 업무 영향, 부서별 이유·확인 자료, 미확인 내용을 표시합니다. 담당 산하와 책임자 요약/실무 상세를 선택한 상태로 PDF를 내려받습니다. 검토 상태는 해당 브라우저에만 저장하며 사내 배정·승인을 뜻하지 않습니다.
- 키가 없는 첫 방문에는 전체 화면 연결 안내를 엽니다. 닫거나 기존 브리핑을 선택할 수 있으며 Jev/GPT는 독립적으로 연결합니다. Jev 판단 실패 시 수집 기사와 완료된 판단을 유지하고 미완료 위치부터 이어갑니다.
- 주차 조회 결과의 GPT 요약은 선택한 담당의 업무 관점을 사용하되, 서버에 저장된 기사 제목·매체·날짜만 요약 근거로 사용합니다. 제목만으로 상세 영향·시행일을 추정하지 않습니다.
- 서비스 소개의 효과 계산은 월 22근무일, 중앙 편집 하루 25분 절감, 실현율 60%라는 가정 모델입니다. 생산성 환산액과 실제 현금 절감을 구분합니다.
- 계리팀 직무 인터뷰와 경력직 공고 링크는 기존 부서 프로필에서 유지합니다.
