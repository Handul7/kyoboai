# 프로토타입 검증 내역

2026년 11월 7일 기준. 샘플 데이터를 대상으로 한 검증이며 실제 언론 보도나 모델의 정확도 평가가 아닙니다.

## 수집 → 분류 → 요약·분석

| 단계 | 현재 데이터와 동작 | 확인한 사항 |
| --- | --- | --- |
| 주요 기사 수집 | 작성한 기사 108건. 제목·샘플 본문·매체명·발행 시각을 보관 | 제목과 ID 중복 없음. 모든 기사가 한 수집 회차에 포함됨 |
| 월요일 보고 | 목·금·토·일 기사 36건 | 날짜의 실제 요일이 목·금·토·일인지 검사 |
| 목요일 보고 | 월·화·수 기사 18건 | 날짜의 실제 요일이 월·화·수인지 검사 |
| Jev 부서 분류 | 작성한 복수 부서 라벨과 판단 근거 | 6개 부서 ID의 유효성, 기사와 보고서 부서의 일치, 대표 예시 7건의 라벨 유지 확인 |
| LLM 요약·분석 | 회차별 24개 + 월간 12개 | 회차별 기사만 근거로 연결. 핵심 요약 72개 항목에 근거 링크 118개를 연결 |
| 사용자별 권한 | 팀 선택 로그인, 관리자, 비로그인 화면 | 팀별 화면 접근 검사와 유효하지 않은 세션 검사. 서버 인증은 추후 연결 |

목요일 요약·분석은 월·화·수 기사에 맞춰 별도로 작성했습니다. 예를 들어 경영전략의 목요일 보고서는 시장 정보·경영 지표·계리 가정을 다루며, 그 회차의 근거가 없는 신사업 분석은 포함하지 않습니다. 디지털·IT의 목요일 보고서는 데이터 정의·예외 처리·접근성을 다룹니다.

샘플 본문이 없던 기사는 제공된 요약을 본문으로 명시했습니다. 가상의 원문 링크를 만들지 않았으며 `sourceUrl`은 `null`입니다. 분류 근거는 작성한 예시이고 Jev의 생성 결과가 아닙니다.

## 자동 검증

```sh
npm run verify
npm run build
```

설치 없이 Node.js 표준 라이브러리만 사용합니다. 검증은 다음 오류를 실제로 넣었을 때 실패하는지도 확인합니다.

1. 월요일 수집 범위에 월요일 날짜를 섞는 오류
2. 목요일 보고서에 월요일 회차의 기사 출처를 넣는 오류
3. 경영전략 보고서의 허용 부서를 디지털·IT로 잘못 지정하는 오류
4. 상품개발의 요약 근거에 다른 기간의 자산운용 기사를 연결하는 오류
5. 11월 월간 보고서에 10월 기사를 포함하는 오류
6. 10월 월간 요약 근거로 11월 기사 ID를 연결하는 오류
7. 월간 보고서의 열람 허용 팀을 잘못 지정하는 오류

## 브라우저 확인

- 부서 선택 화면에는 부서명과 보고서 개수만 표시하고 보고서 본문을 렌더링하지 않음
- 6개 팀 각각에 두 주간의 보고서 4개를 발행일 역순으로 표시
- 36개 보고서의 근거 기사 수와 핵심 요약의 출처 링크가 일치함
- 보고서의 근거 번호를 누르면 해당 출처로 이동하고, 기사를 누르면 샘플 본문과 분류 근거가 열림
- 보고서 주소로 새로고침해도 같은 부서·회차가 열림
- 뒤로 가면 해당 부서의 보고서 목록으로 돌아감
- 로그인 버튼에서 팀을 선택하며 관리자는 모든 팀을 표시
- 비로그인은 전체 뉴스, 팀 로그인은 우리 팀 보고서, 관리자 로그인은 전체 팀 보고서
- 회차별·월간 전환, 보고 월·발행일 범위 필터 및 검색 결과 없음 상태 제공
- 월간 출처는 기사 날짜의 달과 소유 팀을 검사하며 요약의 근거 ID도 같은 범위에 속함
- 제목 하나 뒤에 핵심 요약·주요 인사이트·분석 레포트·뉴스 출처를 순서대로 표시
- 발행일 옆에 근거 뉴스 수 표시. 중복 개요·수집 범위·분류 도구 표시는 제거
- 화면별 발표용 구현 구분 제공. 코딩과 향후 LLM 생성 영역을 구분하고 현재 샘플임을 표시
- 모바일 본문 16px, 기사 제목 18px, 메타데이터 14px 적용

## 검증 범위의 한계

실제 스크래퍼, 언론사 접근, 자동 수집 실행, Jev의 의미 판단 정확도, LLM의 실제 생성 품질, 실제 사용자 인증·권한 차단은 검증하지 않았습니다. 현재는 모두 정적 프로토타입 또는 미구현 단계입니다. 실제 연동 때에는 대표 기사에 대한 부서별 정답과 근거를 마련해 모델 판단을 평가해야 합니다. 올바른 출력 형식이나 출처 ID의 일치만으로 의미적 정확도가 보장되지는 않습니다.
